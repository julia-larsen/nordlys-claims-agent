# bootstrap

`generate_data.py` builds `/data` from a fixed seed. Run it once at the start of
the challenge, commit the output, and leave it alone.

The policy handbook and the ground-truth labels are both derived from the same
constants at the top of the script, so they cannot disagree with each other.

Reading this script before you finish the challenge will show you the rule engine
you are trying to reproduce. That is your call, but it is most of the exercise.
